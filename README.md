# ATSResume — Professional ATS Resume Builder & Optimization Platform

A modern, high-performance web application designed to help job seekers build, analyze, and optimize ATS-compliant resumes with real-time preview, scoring audits, multi-format import, and pixel-perfect A4 PDF export.

Developed and maintained by **Muhammad Faizan**.

---

## Key Features

### 1. Completely Blank Default State & 1-Click Sample Testing
- **Blank Slate by Default:** Clean initial load with zero placeholder data or prefilled assumptions.
- **1-Click Sample Data:** Instant toggle to test layout templates with a realistic engineering CV.
- **Full Form Reset:** Confirmed one-click reset to restore a pristine blank slate.

### 2. Multi-Template ATS-Friendly Gallery
- **Modern Professional (Default):** Clean two-column header with dynamic sidebar for skills and languages.
- **Minimal ATS-Friendly:** Single-column layout with high ATS scannability and clear typography hierarchy.
- **Corporate Executive:** Formal layout with elegant borders, highlighted subheaders, and structured contact badges.
- **Creative Modern:** Contemporary layout with dual-tone header accents, badges, and balanced spacing.
- **Live Template Switching:** Switch templates seamlessly without any data loss.

### 3. Guaranteed 1-Page A4 Precision & Print Matching
- **Automatic Content Density Scaling:** Dynamically detects document height and adjusts typography scaling to ensure a 1-page fit.
- **Print View Matching:** Browser print styles (`@media print`) exactly mirror the downloaded PDF output dimensions (210mm x 297mm A4) with zero unexpected page breaks.
- **Selectable Vector Text Layer:** Exported PDFs include an invisible selectable text stream for ATS parsers alongside high-resolution visuals.

### 4. Professional ATS Audit & Scoring Engine
- **0–100% Real-Time ATS Score:** Instant audit measuring contact completeness, summary strength, work experience bullet points, skills categorization, and formatting compliance.
- **Categorized Checklist:** Detailed breakdowns across Essential, Recommended, and Formatting requirements.
- **Job Description Matcher:** Paste any target job description to calculate keyword match percentage, identify missing skills, and receive tailored suggestions.
- **ATS Plain Text Stream:** View, copy, or download clean plain text format ready for manual ATS portal input.

### 5. Smart Multi-Format CV Import
- **Client-Side Document Parsing:** Extract structured resume data entirely in the browser.
- **Supported File Types:** Adobe PDF (`.pdf`), Microsoft Word (`.docx`), and Image scans (`.jpg`, `.png`, `.webp`).
- **Interactive Review Modal:** Preview and edit extracted fields before applying to the CV builder.
- **Round-Trip Fidelity:** Direct instant restore for PDFs generated by ATSResume.

---

## Tech Stack & Architecture

- **Framework:** Next.js (React 18, App Router)
- **Styling:** Tailwind CSS with custom print and typography utilities
- **Document Processing:** PDF.js (`pdfjs-dist`), Mammoth (`.docx`), Tesseract.js (OCR fallback)
- **PDF Generation:** jsPDF & html2canvas with hybrid vector-text layer injection
- **Icons:** React Icons

## Getting Started

### Prerequisites
- Node.js (v18.x or later)
- npm (v9.x or later)

### Installation
```bash
# Install dependencies
npm install
```

### Development Server
```bash
# Run local dev server on http://localhost:3000
npm run dev
```

### Production Build
```bash
# Build optimized production bundle
npm run build

# Start production server
npm run start
```
